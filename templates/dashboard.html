Cloudinary-Compatible REST API Specs

POST /api/v1/upload

Uploads an image, video, or raw document to Telegram cloud and returns Cloudinary JSON payload.

GET /api/v1/resources

JavaScript / React / Next.js Integration Snippet

const formData = new FormData();
formData.append('file', fileInput.files[0]);

fetch('http://127.0.0.1:8000/api/v1/upload', {
    method: 'POST',
    body: formData
})
.then(res => res.json())
.then(data => {
    console.log('CDN Image URL:', data.secure_url);
    console.log('Thumbnail URL:', data.thumbnail_url);
});

Python (requests) Integration Snippet

import requests

url = "http://127.0.0.1:8000/api/v1/upload"
files = {'file': open('photo.jpg', 'rb')}

res = requests.post(url, files=files)
data = res.json()
print("Cloudinary CDN URL:", data['secure_url'])
